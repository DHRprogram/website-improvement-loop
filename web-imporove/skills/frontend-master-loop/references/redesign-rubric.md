# Redesign Rubric

Scored per-route, averaged at the end.

| Dimension | Weight | Pass Criteria |
|-----------|--------|---------------|
| Visual parity | 20 | Screenshot diff < 5% |
| Performance parity | 15 | LCP/CWV within 10% of baseline |
| Accessibility | 15 | axe-core 0 critical violations |
| SEO parity | 10 | Meta tags match or exceed |
| i18n parity | 10 | All locale keys present |
| Analytics parity | 10 | Events match or exceed |
| Integration parity | 10 | API contracts match |
| Security parity | 5 | No high/critical vulns |
| Cost delta | 5 | Within approved budget |
| Total | 100 | >= 80 to pass |

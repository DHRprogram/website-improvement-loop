Use the website-improvement-loop skill on this repository.

Flow:
1. Ask the four setup questions from SKILL.md. Wait for answers.
2. Phase A (10 iterations) to completion — AUDIT_BASELINE.md, IMPROVEMENT_LOG.md, IDEA_BACKLOG.md.
3. Phase B (12 personas including P11 adversarial and P12 axe-core a11y).
4. Phase C (15–25 ideas → 8–12 pitches). Present to user.
5. STOP. Wait for explicit approval. Do not edit code.
6. Build only approved ideas to Product Quality Bar.
7. Run Regression Guard and write FINAL_REPORT.md.

Do not skip the stop at step 5. Do not merge two ideas into one commit.

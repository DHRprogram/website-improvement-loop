# Idea Generation

## Activation
- What is the first thing a new visitor sees? Could it be faster, clearer, more compelling?
- Is there a tutorial/onboarding flow? Does it reduce drop-off?
- Can we show social proof (testimonials, user count) before sign-up?
- Does the landing page communicate value in under 5 seconds?

## Retention
- What brings users back? Notifications, email, content updates?
- Are there streaks, goals, or progress indicators?
- How personalised is the experience for returning users?
- Can we add weekly digest / summary of activity?

## Conversion
- Where in the funnel do users drop off most?
- Is the pricing page clear and comparable?
- Are there friction points in the payment flow?
- Can we add a free trial, freemium tier, or money-back guarantee?

## Content & SEO
- What keywords does the site rank for? Which are missing?
- Is there a blog / resource section? Does it get traffic?
- Are meta descriptions, OG tags, structured data present?
- Can we add schema markup (FAQ, HowTo, Product, Review)?

## Trust & Social Proof
- Are testimonials, case studies, or logos visible?
- Is there a security / privacy page?
- Are trust badges (SSL, SOC2, VeriSign) displayed?
- Can we add user reviews or ratings?

## Distribution
- Is there a referral / share mechanism?
- Can users invite teammates or collaborators?
- Are there social media share buttons with tracking?
- Can we add "Powered by" badges for viral reach?

## Support & Success
- How do users get help? Chat, email, knowledge base?
- Is there an FAQ page addressing top questions?
- Can we add tooltips / contextual help in the UI?
- What is the average time to first value? Can we shorten it?

## Monetization
- What is the current pricing model? Can it be optimised?
- Are there upsell opportunities (features, capacity, priority)?
- Can we add usage-based billing or pay-as-you-go?
- Is there an affiliate / partnership program?

## Already Have the Data (Highest ROI)
- What usage patterns reveal hidden value? (most-used features)
- Which users churn and why? Can we predict and intervene?
- Which features correlate with retention?
- What A/B tests are running or could run?
